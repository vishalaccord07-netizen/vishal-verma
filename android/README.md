# OutletPulse for Android

This is the native Android wrapper for the OutletPulse field-sales app. It includes the web interface as offline app assets, so outlet records continue to use local device storage.

## Build an APK

1. Install Android Studio (current stable version).
2. Select **Open** and choose this `OutletPulse-Android` folder.
3. Allow Gradle to finish syncing.
4. Choose **Build > Build APK(s)**.
5. Install the generated `app-debug.apk` on an Android device, allowing installs from this source if Android asks.

The app targets Android 7.0 and later. The web assets are located at `app/src/main/assets`.
